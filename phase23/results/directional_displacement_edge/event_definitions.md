# Displacement Event Definitions

Minimum body/ATR24: 0.5
Strength thresholds: (0.5, 0.75, 1.0, 1.25, 1.5)
Structure lookback: 12 bars excluding current bar
Dedup: suppress same-direction events for 3 bars
Horizons: (1, 3, 6, 12, 24)

Follow-through signal time = follow-through bar close.
Failure signal time = failure bar close (next bar beyond midpoint).
